# Python API User Database

A Python project that fetches user data from a REST API and stores it in a SQLite database.

## Features

- Fetch user data from a REST API
- Store users in SQLite
- Display user information
- Filter users by city

## API

This project uses JSONPlaceholder:

https://jsonplaceholder.typicode.com/users

## Requirements

- Python 3
- requests

## Run

```bash
python main.py
